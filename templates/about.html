About This Project

E-Commerce Semantic Search Engine

This system demonstrates semantic product discovery using word embeddings and vector similarity search. Unlike traditional keyword-based search, it understands the meaning behind queries.

4 Search Models

Model 1: Hierarchical Graph Search

Traverses a 5-level product taxonomy (Department → Category → Subcategory → Product Type → Product) with score decay at each level. Best for structured, category-aware queries.

NetworkX BERT Embeddings

Model 2: Flat Semantic Search

Treats all products equally. Encodes product text into 384-dim vectors and finds nearest neighbors using FAISS. Fast, simple, and cross-category.

Sentence-BERT FAISS

Model 3: Enhanced Semantic Search

Extends Model 2 with enriched 300+ word descriptions and metadata re-ranking (rating, reviews, price). Best balance of quality and speed.

Enriched Data Re-ranking

Model 4: LLM-Enhanced Search

Uses a Large Language Model to refine vague/conversational queries before searching. Handles "I need something for..." style queries best.

GPT API Query Refinement

Technology Stack

Python Flask Sentence-Transformers FAISS NetworkX Pandas Pydantic NLTK OpenAI API

Dataset

Based on the Flipkart Products Dataset from Kaggle — 20,000 products across multiple departments with hierarchical categories, descriptions, ratings, brands, and prices.
